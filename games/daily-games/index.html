About this category

Daily puzzles work because they are finite. You cannot grind them, you cannot replay them for a better score, and the only thing to protect is the streak. That turns a two-minute puzzle into a habit rather than a session.

What they train

Consistency and short-form problem solving. The daily set deliberately mixes formats — a picture-logic grid, a number sequence, a Sudoku, five crossword clues and an ordering puzzle — so the same habit is built across different kinds of thinking instead of one.

How to play

Every game opens straight into its board. Tap, click or use the arrow keys; each card above explains the goal in one line.

  • Daily Nonogram — Fill the grid so the row and column counts are satisfied.
  • Daily Sequence — Work out the rule of each sequence and give the next term.
  • Fraction Ladder — Click eight fractions into ascending order against the clock.
  • Daily Sudoku — Solve today's nine-by-nine grid and keep your streak.
  • Daily Clues — Answer five daily clues with one attempt each.
No setup required. Progress is stored in your own browser under mg- keys — clearing site data resets it.
