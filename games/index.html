Three smaller games, same site

Added 27 November 2026

MindGenie AI is a guessing game, and that is still the main event — there is a link back to it at the top of every page here. This corner of the site holds three quieter games for the moments when you want to think rather than guess: a real Sudoku, a five-letter word game and a memory match.

All three run entirely in your browser. There are no accounts, no downloads, no timers counting down at you and no scores sent anywhere. Each page is a single file with its own logic, so once it has loaded it keeps working even if the connection drops.

Sudoku

A generated nine-by-nine grid with four difficulty levels, keyboard or on-screen entry, conflict highlighting and a timer you can ignore.

Word Guess

Six tries at a hidden five-letter word. Green means the right letter in the right place, amber means the right letter in the wrong one.

Words

Memory Match

Twelve cards, six pairs, one move counter. Your best run is kept in your own browser and nowhere else.

Why these three

They are the three kinds of puzzle that suit a short break without asking for an account. Sudoku is deduction with a single correct answer and no vocabulary required; Word Guess is deduction with language in it; Memory Match is neither, which is the point — it is the one here you can play while half-listening to something else.

They also behave well on a phone. Sudoku uses an on-screen number pad as well as arrow keys, Word Guess has its own keyboard under the board so nothing is hidden by the phone's, and the memory grid is a fixed three columns so cards stay large enough to tap.

How the puzzles are made

The Sudoku grid is not copied from a book. Each new puzzle is built by filling an empty grid through backtracking with the candidates shuffled, then removing numbers one at a time and keeping a removal only if a counting solver confirms the puzzle still has exactly one solution. That is why "easy" puzzles are generous with givens and "expert" ones are not: the difficulty is the number of cells removed, not a label attached to a hand-made puzzle.

Word Guess draws from a fixed list of common five-letter words written into the page, so the answer is never a name, a plural or something a dictionary would only admit reluctantly. Memory Match shuffles six emoji pairs with a Fisher-Yates shuffle at the start of every game.

What is stored, and what is not

Nothing about these games leaves your device. Memory Match saves your best move count in your browser's local storage so it survives a refresh; the other two keep no record at all. There is no leaderboard to submit to and no name to enter.
