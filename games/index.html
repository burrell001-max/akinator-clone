Seven small games, one page

Updated 27 November 2026

MindGenie AI is a guessing game, and that is still the main event — there is a link back to it at the top of every page here. This corner of the site holds quieter games for the moments when you want to think rather than guess: breaking a code, solving the day's logic grid, unscrambling letters, or holding a pattern in your head.

All of them run entirely in your browser. No accounts, no downloads, no countdown you did not ask for, and nothing sent anywhere. Each game is one page with its own logic, so it keeps working once loaded.

How the games are built

Every page is hand-written HTML, CSS and vanilla JavaScript with no frameworks, no fonts fetched from a third party and no analytics inside the games themselves. The shared stylesheet holds only the page chrome; each game carries its own small script, which is why loading one game never loads the others.

Puzzles that should be fair are generated rather than copied. The Sudoku grid is built by backtracking and every removal is checked by a counting solver, so each grid has exactly one solution. The daily nonogram is seeded from the calendar date, which means the same grid all day for everyone and a new one tomorrow. The rest use plain randomness, because repeating a codebreaking round would defeat the point.

What is stored, and where

Best scores and daily completion live in your browser's local storage, under keys beginning mg-. They are not sent anywhere, there is no name attached to them, and clearing site data removes them. Where a game tracks a daily completion, it keeps the dates it has seen and a streak count — nothing more.
