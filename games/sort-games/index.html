About this category

Sorting games look trivial and are not. The hard part is never comparing two items; it is holding the whole set in your head while you decide where the middle one goes. Each game here attacks that from a different angle.

What they train

Comparison and ordering under time pressure, plus the working-memory load of tracking a partially built sequence — the same skill as alphabetising a list without writing it down.

How to play

Every game opens straight into its board. Tap, click or use the arrow keys; each card above explains the goal in one line.

  • Sort Sprint — Click the shuffled set into order before the timer runs out.
  • Fraction Ladder — Click eight fractions into ascending order against the clock.
  • Sort Bins — Send each number to the bin that matches the rule.
  • Shift Sort — Repair the scrambled row using the fewest swaps.
  • Timeline — Click six historical events in the order they happened.
No setup required. Progress is stored in your own browser under mg- keys — clearing site data resets it.
