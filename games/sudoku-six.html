How to Play

Fill the grid so that each row, each column and each two-row by three-column box contains 1 to 6 exactly once. Gold digits are givens. Click a cell and use the number pad, or arrow around the grid and type a digit. Backspace clears the selected cell.

Six-by-six Sudoku is often described as the easy version, and it is shorter, but it is not a smaller kind of puzzle: the box shape is different, so the same habits still work and the same traps still catch you. If you have never finished a nine-by-nine grid, this is the version to learn on.

Rules and scoring

  • Rows, columns and the six two-by-three boxes each hold 1 to 6 once.
  • Duplicates are marked red immediately, including a duplicate of a given.
  • Check counts the entries that disagree with the solution; it never fills a cell for you.

  • New puzzle generates a fresh grid and checks that it has a unique solution before dealing it.

Learning on six digits

The reason a smaller grid teaches faster is the number of cells in a box: six instead of nine. When a box already holds four digits, only two cells remain and two candidates are left, so a pair is visible at a glance. On a nine-by-nine grid that same logic takes longer to scan, and beginners tend to start guessing before they have finished the scan.

A second habit worth building here is checking a digit across all six boxes before placing it. With only six digits, a single pass over the board can often place the same digit twice, because each row you fill removes options from two boxes at once. Once you can do that pass without losing count, the nine-by-nine grid stops feeling like a different game and starts feeling like more of the same work.
