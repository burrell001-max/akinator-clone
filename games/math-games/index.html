About this category

None of these need a calculator, and none of them are about long division. They are about the small arithmetic decisions you make constantly — which operation to reach for, whether a value is plausible, and how to work backwards from an answer you already know.

What they train

Arithmetic fluency, estimation and algebraic backwards-reasoning — the habit of asking what the missing value must be instead of computing forward from what you have.

How to play

Every game opens straight into its board. Tap, click or use the arrow keys; each card above explains the goal in one line.

  • Quick Sums — Answer as many arithmetic questions as you can in sixty seconds.
  • Equation Forge — Place operators between four numbers to reach the target.
  • Missing Number — Find the missing value in each equation before time runs out.
  • Fraction Ladder — Click eight fractions into ascending order against the clock.
  • Sort Bins — Send each number to the bin that matches the rule.
  • Daily Sequence — Work out the rule of each sequence and give the next term.
No setup required. Progress is stored in your own browser under mg- keys — clearing site data resets it.
