Codebreaker

A deduction game: find the hidden code from feedback alone.

Guess 1 of 10 Best: —

Green number: right digit, right position. Gold number: right digit, wrong position.

How to play

A hidden code has been chosen from the digits allowed by your difficulty. Type a guess of the right length and submit it. Each guess is scored twice: exact counts digits that are correct and in the right position, and near counts digits that are in the code but in a different position.

Digits can repeat on Medium and Hard, so a guess of 1124 is legal. When a digit appears more than once, the scoring uses the smallest of the counts on each side — three 2s in your guess cannot all match a single 2 in the code.

Rules and scoring

  • Easy: three digits from 1 to 5, no repeats, eight guesses.
  • Medium: four digits from 1 to 6, repeats allowed, ten guesses.
  • Hard: five digits from 1 to 8, repeats allowed, twelve guesses.
  • You win by matching the code exactly. Your score is the number of guesses it took, and the lowest score per difficulty is kept in your browser.
  • Running out of guesses reveals the code, and the round counts as a loss — the best score is not touched.

Strategy that actually helps

Open with a guess that uses distinct digits, even on a difficulty that allows repeats. A code like 1124 tells you less about the other digits than 1234 does, because a repeat wastes one of your scoring slots on information you already had.

Then work by elimination rather than by inspiration. If a digit scores zero exact and zero near, it is not in the code and you can remove it from every future guess. If a digit scores near but never exact, it belongs somewhere other than where you put it, and moving it one place at a time tells you which place. On Hard, the winning habit is to spend the first three guesses mapping which digits exist before trying to order them at all.

Why this is a brain game

Codebreaking is the smallest complete deduction game there is: every guess produces a constraint, and the solution follows from the constraints alone. There is no luck once the code is set and no way to grind — the only thing that improves is your ability to read the feedback. That is also why the score is guesses rather than time.
