About this category

Number games are the easiest to make boring and the hardest to make fair. Everything here is generated rather than hand-authored, so the board is different every time, and every one of them shows you the arithmetic instead of hiding it behind a score.

What they train

Arithmetic fluency, pattern recognition in sequences, and the mental bookkeeping that comes with tracking several numbers at once. The Sudoku boards add constraint reasoning on top: no arithmetic, but the same working-memory load.

How to play

Every game opens straight into its board. Tap, click or use the arrow keys; each card above explains the goal in one line.

  • Merge Up — Slide tiles to combine equal numbers and double them.
  • Codebreaker — Guess the hidden code using exact and near-miss feedback.
  • Pocket Sudoku — Fill the nine-by-nine grid with a number pad made for phones.
  • Sudoku — Fill the grid so every row, column and box holds one to nine.
  • Sort Sprint — Click the shuffled set into order before the timer runs out.
  • Quick Sums — Answer as many arithmetic questions as you can in sixty seconds.
  • Equation Forge — Place operators between four numbers to reach the target.
  • Missing Number — Find the missing value in each equation before time runs out.
  • Daily Sudoku — Solve today's nine-by-nine grid and keep your streak.
  • Sudoku Six — Fill a six-by-six grid with two-by-three boxes.
  • Sudoku Mini — Fill a four-by-four grid with four digits and two-by-two boxes.
  • Digit Echo — Type back the string of digits that flashed on screen.
