How to play

Fill every empty cell so that each row, each column and each of the nine three-by-three boxes contains the digits one to nine exactly once. Click or tap a cell and type a number, or use the pad underneath. Arrow keys move between cells, and backspace clears one.

Two cells in the same row, column or box holding the same digit are shown in red as you type — that is a conflict, and it is never part of a correct solution. "Check answers" marks anything that disagrees with the puzzle's solution without revealing what should be there.

About the puzzles

Each grid is built from scratch: a complete solution is filled in by backtracking with shuffled candidates, then numbers are removed one at a time, and a removal is kept only if a counting solver confirms the grid still has exactly one solution. Easy puzzles keep around forty of the eighty-one numbers, expert puzzles about twenty-five. Nothing is downloaded, and refreshing the page gives you a fresh grid rather than the same one again.

The timer is there for information, not for pressure. It stops when the grid is solved and starts again with a new puzzle.
